# noor (نور)

Privacy-first, fully offline Islamic utility app — Android.

## Features
- **Cosmic Prayer Screen** — Dark theme with animated gold/teal particle waves
- **Adhan Audio** — Play adhan per prayer, choose from 6 iconic muezzins
- **Prayer Times** — Demo data; GPS + Sri Lanka district fallback coming
- **Embossed Allah Calligraphy** — Gold 3-layer text on dark header

## Build
Push to `main` → GitHub Actions builds automatically.
Or: `flutter pub get && flutter build apk --debug`

## Audio
Sourced from github.com/Kiwifu/adhan-mp3 — "Free for Islamic apps"
Place .m4a files in assets/audio/adhan/
